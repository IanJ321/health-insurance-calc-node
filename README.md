Team: OverFlowers

Members: Ian Jung, Andres Bodington

Project Name: Health Insurance Risk Calculator - Node.js

## Additional Requirements
- Node.js
- npm

## Installation Instructions
1. Clone or download this repository
2. Ensure all files are within the same folder:
   - index.js
   - package.json
   - package-lock.json
   - process.json
   - index.html (within static folder)
   - bpChart.png (within static folder)
3. Start the server in Terminal by routing to the folder and using the command "npm start"
   - Server will be hosted on Port 3000 unless stated otherwise
